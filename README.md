# DevOps Notes

A GitHub Pages website containing practical DevOps notes.

## Pages

- `index.html` — table of contents and topic navigation
- `aws-networking.html` — AWS networking notes
- `jenkins.html` — Jenkins from zero to hero

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push these files to the `main` branch.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Save and wait for the deployment to complete.

## Add another topic

1. Create a new page such as `docker.html`.
2. Add a topic card in `index.html`.
3. Add links back to `index.html` from the topic page.
